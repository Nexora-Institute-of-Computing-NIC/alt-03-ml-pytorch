## What this is

The **PyTorch edition** of [CS502 - Machine Learning](https://github.com/Nexora-Institute-of-Computing-NIC/sem-05-cs502-machine-learning). Same topic, same learning outcomes, delivered through PyTorch.

## Why take this edition?

The parent course uses scikit-learn for breadth. This edition goes deeper on neural methods using PyTorch.

## Which edition should I take?

| Choose the parent | Choose this edition |
| :--- | :--- |
| Standard curriculum path | You prefer PyTorch |
| Following the default track | You want to learn PyTorch |
| Most widely-used version | You have existing PyTorch experience |

Both editions are equal in value.
