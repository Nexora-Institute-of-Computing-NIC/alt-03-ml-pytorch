# Parent Comparison

**Parent:** [CS502 - Machine Learning](https://github.com/Nexora-Institute-of-Computing-NIC/sem-05-cs502-machine-learning)
**This edition:** PyTorch

## What stays the same

- Learning outcomes
- Unit structure and lecture topics
- Lab and project briefs
- Assessment scheme

## What changes

- **Language:** PyTorch instead of the parent's language
- **Code:** all examples, starters, and solutions
- **Tooling:** build system, package manager, testing framework
- **Idioms:** examples follow PyTorch conventions

## Differences in detail

- Every model built in PyTorch, not scikit-learn
- Adds autograd from first principles
- Adds neural network labs (MLP, CNN, RNN)
- Assumes Python basics
- Focuses on understanding the training loop, not the API
